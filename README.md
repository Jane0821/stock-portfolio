## 📌 專案動機

在現代投資環境中，許多投資人同時持有多檔股票，卻缺乏一個**整合性的個人化儀表板**來追蹤所有持股的即時狀況。市面上雖然有許多看盤軟體，但往往存在以下問題：

1. **資訊分散**：需要在不同平台之間切換，無法一目瞭然掌握全局
2. **缺乏個人化**：無法記錄自己的買入成本、計算真實損益
3. **價格昂貴**：專業級看盤軟體通常需要付費
4. **操作複雜**：功能過多，反而讓一般使用者感到困惑

因此，本專案開發一個**輕量級、免費、個人化**的股票持倉管理系統，讓投資人能夠：
- 記錄自己的持股成本與數量
- 即時追蹤股價變動與損益
- 透過視覺化圖表快速掌握投資組合配置
- 隨時隨地透過瀏覽器存取

## ✨ 功能特色

### 已完成功能
- 📊 **持倉管理**：新增/刪除持股，自動計算平均成本
- 📈 **即時股價**：透過 yfinance 抓取台股即時收盤價（含備援機制）
- 📉 **K線走勢圖**：5日價格走勢 + MA5 / MA10 均線
- 🥧 **持股配置圓餅圖**：視覺化持股比例
- 📰 **即時財經新聞**：Google News 聚合
- 📊 **市場概況**：成交值、成交量、漲跌家數
- 💬 **股市語錄**：隨機顯示經典投資格言
- 🎨 **台股配色**：紅漲綠跌，符合台灣股市習慣
- 🔄 **備援數據機制**：爬蟲失敗時自動使用快取或模擬數據

### 規劃中功能
- [ ] 串接 Supabase 雲端資料庫（解決數據持久化問題）
- [ ] 支援美股報價
- [ ] 匯出報表功能（PDF / CSV）
- [ ] Email / LINE 推播通知
- [ ] 多帳戶登入支援
